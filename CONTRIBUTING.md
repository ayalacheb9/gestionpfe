

\# Guide de contribution - GestionPFE



\## Organisation des branches



\- main : contient les versions stables.

\- develop : permet d'intégrer les modifications.

\- feature/\* : contient les nouvelles fonctionnalités.

\- fix/\* : contient les corrections.



\## Convention des commits



\- feat: ajout d'une fonctionnalité.

\- fix: correction d'une erreur.

\- test: ajout ou modification des tests.

\- docs: modification de la documentation.

\- ci: modification du pipeline CI/CD.



\## Processus de contribution



1\. Créer une branche à partir de develop.

2\. Effectuer les modifications.

3\. Tester les modifications.

4\. Enregistrer les changements avec un commit.

5\. Envoyer la branche sur GitHub.

6\. Créer une Pull Request vers develop.

7\. Vérifier et fusionner après validation.
